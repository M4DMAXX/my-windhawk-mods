My-Windhawk-Mods

A collection of my local Windhawk mods and modifications.

Currently, this repository contains only an edited version of "Invisible Window Borders" by Bo0ii.
This modification is heavily based on Bo0ii's original source code and retains most of the original mod's implementation and hooking logic, while modifying and extending it to allow window borders to be assigned a custom color instead of simply being made invisible.

The main reason for this modification is a small but annoying Windows behavior: the ugly white window borders that Microsoft forces when using the Windows snapping feature.
Existing mods I found did not address this issue in the way I needed, such as allowing me to choose which color the border should have, so I adapted Bo0ii's original mod to solve it.
